# ラボ02：宣言型エージェントにカスタムナレッジを追加

## ラボ シナリオ

ラボ01で作成した「製品サポート」エージェントは、役割と口調は決まっていますが、Contoso Electronics 社の製品について何も知らない状態です。

このラボでは、製品資料（Word ファイル8本）を OneDrive に置き、エージェントの「ナレッジ」として登録します。ナレッジを登録すると、エージェントは資料の内容に基づいて回答し、どの資料から答えたか（引用元）を表示できるようになります。

![map-lab02](./media/map-lab02.png)

![sampledata](./media/sampledata.png)

![flow-lab02](./media/flow-lab02.png)

![ba-lab02](./media/ba-lab02.png)

このラボでは以下のタスクを実施します。

　**タスク１：サンプルデータをダウンロードする**

　**タスク２：OneDrive にサンプルデータをアップロードする**

　**タスク３：エージェントにナレッジを追加する**

　**タスク４：エージェントの指示を更新する**

　**タスク５：Copilot Studio でエージェントをテストする**




## 予想時間: 25分



## タスク1 - サンプルデータをダウンロードする

> **このタスクの目的：** 講師が用意したサンプルデータ（製品資料8本）を、自分のパソコンにダウンロードします。

1. 以下のリンクをクリックして、サンプルデータ（Products.zip）をダウンロードします。

   ```
   https://github.com/ctct-edu/MS-4022/raw/main/Allfiles/Products.zip
   ```

   > 注：ダウンロードした Products.zip は、パソコンの「**ダウンロード**」フォルダーに保存されます。

   

2. エクスプローラーで「**ダウンロード**」フォルダーを開き、**Products.zip** を右クリックして「**すべて展開**」をクリックします。表示された画面で「**展開**」をクリックします。

   

3. Word ファイル8本が入った「**Products**」フォルダーができたことを確認します。

   | ファイル名                 | 内容                         |
   | -------------------------- | ---------------------------- |
   | Contoso Quad.docx          | 法人向けドローンの仕様・よくある質問 |
   | Eagle Air.docx             | 高性能ドローンの仕様・よくある質問 |
   | Gimbal Case.docx           | ドローン用ケースの仕様・よくある質問 |
   | Mark8.docx                 | 一般向けドローンの仕様・よくある質問 |
   | Mark8 controller.docx      | Mark8 用コントローラーの仕様・よくある質問 |
   | Repairs.docx               | 修理サービスの案内           |
   | Returns.docx               | 返品ポリシー                 |
   | Warranty.docx              | 製品保証                     |

   



## タスク2 - OneDrive にサンプルデータをアップロードする

> **このタスクの目的：** エージェントが読む資料を、自分の OneDrive に置きます。

1. ラボ00で使用している InPrivate ウィンドウで新しいタブを開き（キーボードの **Ctrl** ＋ **T**）、アドレスバーに以下の URL を入力して **Enter** キーを押します。

   ```
   https://ctctedu-my.sharepoint.com/
   ```

   ![lab02-01](./media/lab02-01.png)

   

2. 「**アカウントを選択する**」と表示された場合は、講師から事前に配布したアカウント（`ms-4022-XX`）をクリックします。

   > 注：XXはご自身のアカウント番号です。

   ![lab02-02](./media/lab02-02.png)

   

3. 「**Copilot in OneDrive でファイルをさらに活用する**」と表示された場合は、「**今はしない**」をクリックします。

   ![lab02-03](./media/lab02-03.png)

   

4. OneDrive の画面が表示されたら、画面右上の「**＋ 作成またはアップロード**」をクリックします。

   ![lab02-04](./media/lab02-04.png)

   

5. 「**独自の AI アシスタントを構築します**」と表示された場合は、「**閉じる**」をクリックします。

   ![lab02-05](./media/lab02-05.png)

   

6. 表示されたメニューから「**フォルダーのアップロード**」をクリックします。

   ![lab02-06](./media/lab02-06.png)

   

7. 「**アップロードするフォルダーを選択してください**」の画面で、左側の「**ダウンロード**」をクリックし、タスク1で展開した「**Products**」フォルダーをクリックして、「**アップロード**」をクリックします。

   > 注：「このサイトにファイルをアップロードしますか?」と表示された場合は、「**アップロード**」をクリックしてください。

   ![lab02-07](./media/lab02-07.png)

   

8. 画面右下に「**9 個のアイテムを ドキュメント にアップロードしています**」と表示されるので、完了するまで待ちます。

   ![lab02-08](./media/lab02-08.png)

   

9. 画面左の「**マイ ファイル**」をクリックし、「**Products**」フォルダーが表示されていることを確認します。「**Products**」をクリックして開きます。

   ![lab02-09](./media/lab02-09.png)

   

10. 8つのファイルがアップロードされていることを確認します。

    ![lab02-10](./media/lab02-10.png)

    



## タスク3 - エージェントにナレッジを追加する

> **このタスクの目的：** OneDrive に置いた資料を、エージェントのナレッジとして登録します。

1. Copilot Studio（クラシック エクスペリエンス）のタブに戻ります。画面左の「**エージェント**」をクリックし、一覧から「**Microsoft 365 Copilot**」をクリックします。

   ![lab02-11](./media/lab02-11.png)

   

2. 「**概要**」タブの「**エージェント**」の欄にある「**製品サポート**」をクリックします。

   ![lab02-12](./media/lab02-12.png)

   

3. 「**ナレッジ**」の欄にある「**＋ ナレッジの追加**」をクリックします。

   ![lab02-13](./media/lab02-13.png)

   

4. 「**ナレッジの追加**」の画面で「**SharePoint**」をクリックします。

   > 注：OneDrive は SharePoint の仕組みで動いているため、「SharePoint」を選択して OneDrive のフォルダーを指定します。

   ![lab02-14](./media/lab02-14.png)

   

5. 「**SharePoint サイトの URL を入力します**」の欄をクリックします。

   ![lab02-15](./media/lab02-15.png)

   

6. 以下の URL を入力し、「**追加**」をクリックします。

   > 注：URL の中の **XX** は、ご自身のアカウント番号に置き換えてください（例：アカウントが ms-4022-05 の場合は `ms-4022-05_ctctedu_onmicrosoft_com`）。

   ```
   https://ctctedu-my.sharepoint.com/personal/ms-4022-XX_ctctedu_onmicrosoft_com/Documents/Products
   ```

   ![lab02-16](./media/lab02-16.png)

   

7. 一覧に「**Products**」が追加されたことを確認し、「**エージェントに追加する**」をクリックします。

   ![lab02-17](./media/lab02-17.png)

   

8. 追加が完了するまで待ちます。

   ![lab02-18](./media/lab02-18.png)

   

9. 「**ナレッジ**」の欄に「**Products**」が表示され、「**準備完了**」になったことを確認します。

   > 注：「準備完了」になるまで数分かかる場合があります。

   ![lab02-19](./media/lab02-19.png)

   



## タスク4 - エージェントの指示を更新する

> **このタスクの目的：** エージェントの指示に「資料を使うこと」「引用元を示すこと」「資料にない場合の対応」を追加します。

1. 「**詳細**」の欄の右上にある「**編集**」をクリックします。

   ![lab02-20](./media/lab02-20.png)

   

2. 「**手順**」の入力欄の文章をすべて消してから、以下の文章を貼り付けます。貼り付けたら、「**詳細**」の欄の右上にある「**保存**」をクリックします。

   ```
   - あなたは、Contoso Electronics社の製品に関する質問に回答するエージェントです。
   - すべての回答は、ユーザーの質問やコメントに対して心を込めて感謝の言葉を伝えることから始め、その後に質問やコメントに回答してください。
   - 情報源として、OneDriveの「Products」フォルダーにあるドキュメントを使用してください。
   - 必要な情報が見つからない場合は、担当チームに問い合わせるよう案内してください。
   - 回答は簡潔にし、必ず引用元を示してください。
   ```

   > 注：「手順」は、ラボ01の「指示」と同じものです。

   ![lab02-21](./media/lab02-21.png)

   



## タスク5 - Copilot Studio でエージェントをテストする

> **このタスクの目的：** 資料に基づいて回答し、引用元が表示されるかを確認します。資料にない質問への対応も確認します。

1. 画面右側の「**エージェントをテストする**」の「**新しいチャット**」をクリックします。入力欄に以下の文章を入力し、送信ボタンをクリックします。

   ```
   Eagle Airについて教えてください
   ```

   回答の下に、引用元として「**Eagle Air.docx**」が表示されていることを確認します。

   > 注：回答の内容は毎回異なります。引用元が表示されていれば問題ありません。
   >
   > 注：資料に基づいた回答にならない場合は、資料の読み込みが完了していない可能性があります。10〜15分ほど待ってから再度お試しください。

   ![lab02-22](./media/lab02-22.png)

   

2. 続けて、以下の文章を入力して送信します。

   ```
   農家の方におすすめの製品はどれですか？
   ```

   Eagle Air が推奨され、引用元が表示されていることを確認します。

   ![lab02-23](./media/lab02-23.png)

   

3. 続けて、以下の文章を入力して送信します。

   ```
   Contoso QuadよりEagle Airが適している理由を説明してください
   ```

   2つの製品の資料に基づいて比較されていることを確認します。

   ![lab02-24](./media/lab02-24.png)

   

4. 最後に、資料に載っていない質問をします。以下の文章を入力して送信します。

   ```
   Mark8はいつ発売されましたか？
   ```

   資料に発売日の記載がないため、**担当チームへの問い合わせを案内する回答**になっていることを確認します。

   ![lab02-25](./media/lab02-25.png)

   

以上で本ラボは完了です。
